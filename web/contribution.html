Contribution

Add new languages, icons, and even functions to Toolbox.

If you'd like to help me build Toolbox, contributing is a great way to take some of the load off my shoulders.

Localization

Localization is something that is particularly challenging for me, as I only speak German and English. Toolbox is now available in English, German, Spanish, French, Dutch, Polish, Portuguese and Swedish, but to be honest, everything except German and English was translated with the help of AI. So if you speak one of these languages, a native speaker checking the translations would mean a lot to me. And if you speak any other language, even better!

How can I do this?

Toolbox is translated on Crowdin. All you need is a browser and a free Crowdin account, thus no Mac, no Xcode, no files to send around. Pick your language, translate or fix whatever you like, and I'll bring your work into the next update. :D

Is your language missing? Just send me an email and I'll add it to Crowdin. Before a new language goes live, you'll be the first to try it in a private beta to make sure everything appears as expected.

Of course, you will be credited in the app's "Special Thanks" section so everyone knows you contributed that amazing work! Thank you in advance! 🫶

Icons

New ✨fancy✨ icons are always exciting! Customizing your homescreen with icons you love is a great way to personalize Toolbox. Right now, there are ten versions of the icon (including a Pride one 🏳️‍🌈) but I'd love to have more. The icons are made with Apple's Icon Composer, which comes with Xcode, so you can download the original icon file and create your own icon based on it. I think altering the glyph would be too drastic, though if not for a good reason.

Requirements

  • A new icon
  • Don't change the glyph too much. It should still be recognizable as the same icon. Small changes are fine.
  • Made in Icon Composer and send me the .icon file
  • It looks good in the light, dark and tinted appearances
  • You should own the rights to what you create, so no copyrighted content
  • If you use assets from the internet, please provide a source

Once you're finished, just send the files to me via email or even file a pull request on Toolbox's GitHub repository if you prefer so.

You'll be credited in the app's "Special Thanks" section, so everyone knows you did that awesome work! Thank you in advance! 🫶

Functions

If you know how to code and want to add a new function to Toolbox, this is your chance! There's not much to explain here. Toolbox is written in Swift, and while it's relatively tidy, it's not perfect. 😅 If you'd like to contribute, ignore the messy commits I made when frustrated at 3 AM and head over to Toolbox's GitHub repository. There, you can find the source code. Fork the repo, make your changes, and when you're done, make sure everything is committed, create a pull request, and include a brief description. I'll review and test your changes. If everything works and the feature makes sense, I'll accept your pull request.

What changes will be accepted?

Generally, I'll accept any changes as long as they make sense and aren't overly complex. For example, a speed test would make sense because iOS doesn't have that built-in and it's not too difficult to implement. However, a flashlight wouldn't be accepted, since iOS already includes that functionality, and neither would a full blown AAA game.

Can I use AI?

Sure! If AI tools help you build a feature, go for it. Just mention briefly in your pull request that you used AI (Co-Authorship is enough), and make sure you understand and have tested the code you're submitting. I'll review it like any other contribution.

You'll be credited in the app's "Special Thanks" section, so everyone knows you contributed that amazing work! Thank you in advance! 🫶
