Barcode Scanner

Read barcodes and QR codes with your camera and keep every scan.

Point your iPhone at a barcode or QR code and Toolbox reads it. Every scan lands in a history, so you can come back to it later, copy what it says or show the code to someone else.

What it can do

  • All common codes: QR code, Aztec, Data Matrix, PDF417, EAN-8, EAN-13, UPC-E, Code 39, Code 93, Code 128, ITF-14 and Interleaved 2 of 5.
  • History: every scanned code is saved with its type and the date of the scan. Swipe to delete the ones you don't need.
  • Copy the content: tap the content of a code to copy it, for example a link, a product number or a ticket code.
  • Show it again: QR, Aztec, PDF417 and Code 128 codes are drawn again from the content, so someone else can scan them from your screen.
  • Private: the history is stored only on your iPhone.

How to scan a barcode

  1. Open Toolbox and tap Barcode Scanner.
  2. Tap the scan button and allow camera access.
  3. Hold the code in front of the camera, it is read automatically.
  4. Tap a code in the history to see and copy its content.
