QR Code Generator

Turn a link, a text, your Wi-Fi or an email address into a QR code.

Want guests to join your Wi-Fi without spelling out the password, or put a link on a flyer? Type it into Toolbox and the QR code appears right away. Share it, print it or save it to your photos.

What it can do

  • Links: a QR code that opens a website when scanned.
  • Text: any note, code or message, up to what fits into a QR code.
  • Wi-Fi: network name, password and encryption (WPA, WEP or none), hidden networks too. Scanning the code joins the network, no typing needed.
  • Email: receiver and subject, so scanning the code starts a new email.
  • Share it: send the QR code with any app, print it or save it as an image.
  • Works offline: the code is created on your iPhone, nothing is sent to a server.

How to make a QR code

  1. Open Toolbox and tap QR-Code Generator.
  2. Choose what the code should contain: URL, text, Wi-Fi or mail.
  3. Fill in the fields, the QR code updates as you type.
  4. Tap the share button to send, print or save it.
